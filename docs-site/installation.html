Getting Started

Installation, Verification & Migration

Highbeam installs without modifying project source code, adding npm runtime dependencies, or requesting API credentials. Every configuration merge creates a local backup before writing.

Prerequisites & Runtime Requirements

  • Node.js >= 20.0.0: Required on your system PATH so host lifecycle hooks can invoke node directly. Verify with node --version.
  • SQLite & Automatic Fallback: On Node.js builds providing built-in node:sqlite (Node 22.5+ and modern Node 20 releases), @ctxtop/engine-node opens session databases with SQLITE_OPEN_READONLY and activates local FTS5 archival. On environments without node:sqlite (or when CTXTOP_FORCE_NO_SQLITE=1 is set), the engine falls back automatically to read-only JSONL byte-offset slicing.
  • Git (Optional, Recommended): Enables DET-01 git safety checks, DET-03 lockfile drift checks, DET-31 cross-worktree git merge-tree conflict sensors, and Cost Radar worktree topology.

Clean Installation Across Surfaces

Always preview changes first with --dry-run if you manage custom hook pipelines in settings.json or hooks.json.

1. Unified Dual-Host Installation

Use ctxtop init --all when you work in both Google Antigravity and Claude Code on the same machine:

Preview and Run Unified Installer
# Preview planned file paths without writing
npx ctxtop init --all --dry-run

# Perform non-destructive dual-host installation
npx ctxtop init --all

2. Google Antigravity Installation

You can install Highbeam either at the workspace level (.agents/plugins/) or globally across all workspaces (~/.gemini/config/plugins/), or clone from GitHub for local development:

Google Antigravity Setup Options
# Option A: Workspace plugin installation
npx attention-horizon-antigravity init --workspace

# Option B: Global user installation via ctxtop
npx ctxtop init --antigravity --global

# Option C: Local source checkout & 3-way mirror sync
git clone https://github.com/Gizzant/context-horizon.git
cd context-horizon
node scripts/sync_mirrors.mjs
node bin/ctxtop.mjs verify --json

3. Claude Code Installation (Lean vs. Full Hooks)

For Claude Code, ctxtop install (or ah-claude install) merges lifecycle hooks and the ah-statusline bridge into either .claude/settings.json (default project scope) or ~/.claude/settings.json (--global / -g), preserving any unrelated hooks you already use:

Claude Code Project vs. Global Installation
# Recommended: Lean hook profile in global ~/.claude/settings.json
npx ah-claude install --global --lean-hooks

# Project-local full hook profile (.claude/settings.json)
npx ah-claude install --project --full-hooks

You can also load the plugin directory directly in Claude Code via .claude-plugin/plugin.json, which registers all six slash commands (/horizon, /cost-radar, /inspect, /handoff, /precheck, /evolve) and points to hooks/hooks.json.

4. Cursor & Windsurf MCP Registration

To expose Highbeam telemetry, C* break-even checks, and multi-agent Scope Lock Leases inside Cursor or Windsurf:

Register @ctxtop/mcp in .cursor/mcp.json
# Project-scoped .cursor/mcp.json
npx ctxtop init --mcp

# Global ~/.cursor/mcp.json
npx ctxtop init --mcp --global

Authentication & OAuth Seat Safety

Highbeam requires zero external authentication. It never prompts for Anthropic, Google Cloud, or OpenAI API keys because every detector and score calculation is deterministic local JavaScript.

Account & OAuth Seat Safety Protocol

To protect interactive developer accounts from automated abuse lockouts, Highbeam enforces three hard boundaries across its runtime and test suite: (1) it never reads ~/.gemini/oauth_creds.json or Windows Credential Manager gemini:antigravity secrets (enforced by DET-02); (2) its test harnesses never spawn headless gemini or agy CLI processes using "selectedAuthType": "oauth-personal"; and (3) its coaching rules guide agents to batch searches and edits into 1-2 consolidated tool calls per turn rather than unthrottled parallel subagent bursts.

Safe Deduplication, Migration & Uninstallation

Upgrading from v3.x (`ga-visualizer` / `agy-horizon` legacy IDs) or switching from project-level hooks to global hooks takes two commands:

  • Legacy Config Migration: Legacy v3 detector IDs inside existing config files are automatically mapped to canonical v4.0 DET-01..DET-32 identifiers via migrateLegacyHorizonConfig.
  • Hook Deduplication: Run npx ctxtop init --claude --dedupe to strip duplicate or outdated Highbeam hook entries from settings.json while keeping custom third-party hooks untouched.
  • Orphaned Antigravity Brain Recovery: After an Antigravity IDE profile migration, run npx ctxtop doctor --recover-brain --dry-run (then omit --dry-run) to relink orphaned brain directories.

Clean Uninstallation

Remove Hooks and Optional Local Caches
# 1. Remove Highbeam hooks & statusLine from Claude Code settings
npx ctxtop uninstall --global
npx ctxtop uninstall --project

# 2. Optional: remove local telemetry caches and runtime control latches
rm -rf ~/.ctxtop ~/.attention-horizon .claude/cache/ah_live_state_*.json .attention-horizon.json

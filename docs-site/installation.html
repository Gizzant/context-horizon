Getting Started

Installation, Verification & Migration

Highbeam installs cleanly without touching your source code, adding npm dependencies, or asking for API keys. Every config update saves a local backup before writing.

Prerequisites & Runtime Requirements

  • Node.js >= 22.13.0: Needed on your system PATH so host hooks can run node directly. Check with node --version.
  • SQLite, FTS5 Polyfill & Fallback: On the supported Node versions (22.13+, with built-in node:sqlite), @ctxtop/engine-node opens session databases with SQLITE_OPEN_READONLY and enables local FTS5 log search. If a Node 22 build lacks SQLITE_ENABLE_FTS5, src/engine-node/db/probe.mjs supplies a drop-in USING fts5(...) table and MATCH snippet polyfill. When node:sqlite is absent (or CTXTOP_FORCE_NO_SQLITE=1 is set), Highbeam falls back to read-only JSONL byte-offset reads.
  • Git (Optional, Recommended): Powers DET-01 git safety checks, DET-03 lockfile drift checks, DET-31 worktree git merge-tree conflict checks, and Cost Radar worktree maps.

1. Unified Dual-Host Installation

Use highbeam init --all-hosts to configure Google Antigravity, Claude Code, and supported MCP hosts (Cursor, Windsurf, Codex CLI, Gemini CLI) in one pass:

Preview and Run Unified Installer
# Preview planned file paths without writing
npx highbeam-cli init --all-hosts --dry-run

# Perform non-destructive multi-host installation
npx highbeam-cli init --all-hosts

2. Google Antigravity Installation

Install Highbeam for one workspace (.agents/plugins/) or globally across all projects (~/.gemini/config/plugins/). You can also clone the repo for local work:

Google Antigravity Setup Options
# Option A: Workspace plugin installation
npx highbeam-cli init --workspace

# Option B: Global user installation via highbeam-cli
npx highbeam-cli init --antigravity --global

# Option C: Local source checkout & 3-way mirror sync
git clone https://github.com/Gizzant/context-horizon.git
cd context-horizon
node scripts/sync_mirrors.mjs
node bin/ctxtop.mjs verify --json

3. Claude Code Installation (Lean vs. Full Hooks)

For Claude Code, npx highbeam-cli init --claude (project) or --global (all projects) merges hooks and the ah-statusline bar into .claude/settings.json (project scope) or ~/.claude/settings.json (--global). Your existing custom hooks stay untouched:

Claude Code Project, Global & Native Plugin Marketplace
# Native Claude Code Plugin Marketplace install
/plugin marketplace add Gizzant/context-horizon

# Recommended: Lean hook profile in global ~/.claude/settings.json
npx highbeam-cli init --claude --global --lean-hooks

# Project-local full hook profile (.claude/settings.json)
npx highbeam-cli init --claude --full-hooks

You can also build and install the VS Code / Cursor / Antigravity sidebar extension locally from extensions/vscode-highbeam/highbeam-4.5.0.vsix via npm run build:vsix, or load the plugin folder directly via .claude-plugin/plugin.json and .claude-plugin/marketplace.json. That adds all six slash commands (/horizon, /cost-radar, /inspect, /handoff, /precheck, /evolve) and wires up hooks/hooks.json. During highbeam install or highbeam init --claude, inspectClaudeBinaryCapabilities() scans your Claude Code binary so older CLI builds remain compatible.

Authentication & OAuth Seat Safety

Highbeam needs zero cloud login or API keys. It never asks for Anthropic, Google Cloud, or OpenAI keys because every rule and score runs locally in JavaScript.

Account & OAuth Seat Safety Protocol

Highbeam enforces three strict rules across its runtime and tests to prevent automated account lockouts. First, it never reads ~/.gemini/oauth_creds.json or Windows Credential Manager gemini:antigravity secrets (enforced by DET-02). Second, its tests never launch headless gemini or agy CLIs with "selectedAuthType": "oauth-personal". Third, its coaching rules steer agents to batch searches and edits into 1-2 tool calls per turn instead of parallel subagent bursts.

Safe Deduplication, Migration & Uninstallation

Upgrading from v3.x (`ga-visualizer` / `agy-horizon` IDs) or moving from project hooks to global hooks takes two quick steps:

  • Legacy Config Migration: migrateLegacyHorizonConfig maps old v3/v4.0 rule names to v4.5.0 DET-01..DET-32 IDs automatically.
  • Hook Deduplication: Run npx highbeam-cli init --claude --dedupe to clean out duplicate or old Highbeam entries from settings.json. Your other third-party hooks stay intact.
  • Orphaned Antigravity Brain Recovery: After an Antigravity IDE profile move, run npx highbeam-cli doctor --recover-brain --dry-run first. Then run it without --dry-run to relink orphaned brain folders.

Clean Uninstallation

Remove Hooks and Optional Local Caches
# 1. Remove Highbeam hooks & statusLine from Claude Code settings
npx highbeam-cli uninstall --global
npx highbeam-cli uninstall --project

# 2. Optional: remove local telemetry caches and runtime control latches
rm -rf ~/.ctxtop ~/.attention-horizon .claude/cache/ah_live_state_*.json .attention-horizon.json

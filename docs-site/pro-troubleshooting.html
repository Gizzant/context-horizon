3. Platform Quirks & Diagnostic Playbook

Every failure state below maps to a deterministic check or one-command local repair. Start with npx ctxtop doctor to inspect all host contracts and recent non-fatal hook errors.

Upstream HTTP 400 on Image / Screenshot Attachments (DET-20)

Symptom: Submitting a screenshot while Google AI Credit Overages are active fails upstream with HTTP 400 Bad Request ("Unable to process input image").
Resolution: Configured in config/platformQuirks.json, DET-20 warns before submission when overage mode and image media coincide. Submit text/DOM snippets only (or delegate DOM inspection) until Base Quota resets.

Preventing 168-Hour Hybrid Quota Lockouts (DET-16)

Symptom: Aggressive parallel subagent fan-out near quota exhaustion can trigger upstream 7-day (168-hour) rate lockouts.
Resolution: Keep DET-16 enabled. It throttles concurrency to a single worker at 80% quota utilization, prompts explicit confirmation at 90%, and bounds individual subagents to 40,000 tokens and 12 turns.

Windows PowerShell 5.1 Command Chaining

Symptom: Shell commands containing POSIX && operators fail with a parser error in Windows PowerShell 5.1.
Resolution: Wrap compound verification commands inside cmd /c "node scripts/sync_mirrors.mjs && node bin/ctxtop.mjs verify --json" or execute semicolon-separated statements cleanly.

Tool Execution Appears Hung or Frozen

Symptom: Tool calls wait indefinitely at the PreToolUse boundary (up to 10 minutes) or immediately reject with Execution halted by control latch.
Resolution: Check whether the session was placed into PAUSED or terminal ABORTED state via ctxtop control:

Inspect and Clear Runtime Control Latch
npx ctxtop control status --session default
npx ctxtop control resume --session default
# If ABORTED (terminal), remove the session latch file to reset:
rm ~/.ctxtop/runtime/default.ctl

Missing node:sqlite, Orphaned Brains & Bloated state.vscdb

  • Force JSONL Mode: If an older custom Node 20 binary lacks experimental node:sqlite, set CTXTOP_FORCE_NO_SQLITE=1; Highbeam switches cleanly to read-only JSONL offset slicing.
  • Relink Antigravity Brains: Run npx ctxtop doctor --recover-brain --dry-run (then omit --dry-run) to repair broken brain links after IDE profile upgrades.
  • Compact Cursor SQLite Storage: Run npx ctxtop doctor --gc-cursor --vscdb <path-to-state.vscdb> --dry-run to preview orphan-row reclamation before compacting.
  • Zero-PII Bug Reports: Run npx ctxtop doctor --diagnostic > diagnostic.md to generate a sanitized issue bundle with home directories and usernames scrubbed.

3. Platform Quirks & Diagnostic Playbook

Every issue below has a fast check or a one-line local fix. Run npx highbeam-cli doctor first to check host setup and recent hook logs.

Upstream HTTP 400 on Image / Screenshot Attachments (DET-20 Vision Quirk / DET-28)

Symptom: Sending a screenshot while Google AI Credit Overages are active fails with HTTP 400 Bad Request ("Unable to process input image").
Resolution: Alongside its primary concurrent file-scope lockfile role (.agents/locks/active_scopes.json), DET-20 (configured via config/platformQuirks.json, with the DET-28 quota-overage guard) warns before sending images during AI Credit Overage mode. Send plain text or DOM snippets until Base Quota resets.

Preventing 168-Hour Hybrid Quota Lockouts (DET-16)

Symptom: Launching many parallel subagents near your quota limit can trigger a 7-day (168-hour) upstream lockout.
Resolution: Keep DET-16 on. It caps workers to one at 80% quota use, asks before continuing at 90%, and limits each worker to 40,000 tokens and 12 turns.

Windows PowerShell 5.1 Command Chaining

Symptom: Shell commands using && fail with a parser error in Windows PowerShell 5.1.
Resolution: Wrap chained commands in cmd /c "node scripts/sync_mirrors.mjs && node bin/ctxtop.mjs verify --json", or separate steps with semicolons.

Tool Execution Appears Hung or Frozen

Symptom: Tool calls pause at PreToolUse (up to 10 minutes) or fail right away with Execution halted by control latch.
Resolution: Check if the session was set to PAUSED or ABORTED via highbeam control:

Inspect and Clear Runtime Control Latch
npx highbeam-cli control status --session default
npx highbeam-cli control resume --session default
# If ABORTED (terminal), remove the session latch file to reset:
rm ~/.ctxtop/runtime/default.ctl

Missing node:sqlite / SQLITE_ENABLE_FTS5, Binary Capabilities & Bloated state.vscdb

  • Automatic FTS5 Polyfill (Node 22): If your Node 22 binary lacks SQLITE_ENABLE_FTS5, src/engine-node/db/probe.mjs loads a built-in SQLite table and snippet polyfill automatically. Set CTXTOP_FORCE_FTS5_POLYFILL=1 to test it directly.
  • Force JSONL Mode: Highbeam needs Node 22.13 or newer. If SQLite misbehaves on your build, set CTXTOP_FORCE_NO_SQLITE=1. Highbeam switches cleanly to read-only JSONL offset reads.
  • Claude Binary Capability Warnings: If highbeam doctor shows [WARN] claude_pre_model_switch, run npx highbeam-cli doctor --json (or set CLAUDE_BIN to your Claude Code binary path). That checks PreModelSwitch, PostModelSwitch, and supportsAskDecision support.
  • Relink Antigravity Brains: Run npx highbeam-cli doctor --recover-brain --dry-run first, then drop --dry-run to fix broken brain links after IDE profile upgrades.
  • Compact Cursor SQLite Storage: Run npx highbeam-cli doctor --gc-cursor --vscdb <path-to-state.vscdb> --dry-run to preview space savings before compacting.
  • Zero-PII Bug Reports: Run npx highbeam-cli doctor --diagnostic > diagnostic.md to create a clean debug bundle with usernames and home paths removed.

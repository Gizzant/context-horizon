1. Replicated 72-Run Live A/B (T01–T08)

Source artifact: highbeam_ab_results.json (anthropic/claude-sonnet-5.5, 8 seeded doc/log/audit tasks × 3 replications × 3 arms = 72 runs with full HTTP wireObs telemetry). To isolate PreToolUse Read clamping and PostToolUse FTS5 compression, run_highbeam_ab.mjs seeds T01–T08 with synthetic oversized spec/audit docs and noisy diagnostic logs — in contrast to the unseeded small-file navigation suite in Section 2 (T09–T11, 0/27 clamps). We ran the HIGHBEAM arm with configureShield({ action: 'enable' }) (and included a middle ablation arm, HIGHBEAM_SHIELD_OFF); fresh v4.4.1 installs default to clamp-only mode: 'auto'.

3. 45-Run Model-Switch Wire Study & 19-Fixture CLI Compression

  • Model downgrade penalty (45 runs / 540 turns, $22.72 settled): Switching Opus 4.6 -> Sonnet 4.6 at Turn 6 on a ~58k context collapsed Turn-6 cache hits to 0.0% (+$0.1783 spike), increasing 12-turn spend from $0.7789 to $0.8611 (+10.6%). Effort changes on 4.6 also broke cache (+$0.0853), while claude-sonnet-5-5 and claude-opus-5-5 preserved prefix cache across effort steps (EMPIRICAL_BENCHMARKS.md).
  • 19-Fixture Offline FTS5 CLI Parity (npm run bench:parity): Across 19 noisy tool outputs (F01–F19 across pytest, vitest, tsc, cargo, go test, eslint, git, docker, kubectl, maven, gradle, dotnet, make, playwright, rspec, phpunit, deno, ctest), Highbeam achieved 96% reduction (54,415 -> 2,176 tok), 100% recall (52/52), and 100% BM25 retrieval (19/19), while excluding cat/head/tail/sed/awk/grep/rg/jq (ANTIGRAVITY_AND_COMPRESSION_BENCHMARK.md).

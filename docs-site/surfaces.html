Google Antigravity Surface Architecture

Inside Google Antigravity (App, IDE, and agy CLI), Highbeam operates as a full sidecar-backed plugin registered under attention-horizon-antigravity (and workspace mirror agy-horizon-flightcheck).

Sidecar Daemon & Edward Tufte WebView

The manifest in sidecars/horizon-daemon/sidecar.json launches node --no-warnings server.mjs on loopback port 62935 (scanning 62935..62945 if busy) and mounts directly into Antigravity's auxiliary side pane via SIDECAR_UI_ENTRYPOINT_AUX_PANE. You can also open it from chat via the sidecar://agy-horizon-flightcheck/horizon-daemon/ pill or run npx ctxtop --serve in any browser.

The WebView enforces strict UI invariants verified in automated JSDOM gates:

  • 1-Click Compaction Copy: Always renders #btnCompactPrimary and #btnCopyParameterizedCompact beside #compactInstruction and #compactReclaim so you can copy a parameterized /compact prompt in one click.
  • Active Source File Protection: The Ignore file (.antigravityignore) action is offered exclusively on lockfiles, logs, build artifacts, and scratch outputs (isIgnorablePath), never on active source code files.
  • 3-Way Mirror Parity: When local plugin directories (~/.gemini/config/plugins/agy-horizon and agy-horizon-flightcheck) exist on disk, node scripts/sync_mirrors.mjs keeps horizon_panel.html and src/core/*.mjs byte-for-byte identical via SHA-256 verification.

Subagents, /browser, /swarm & Workspace Modes

Antigravity provides native multi-agent delegation primitives that Highbeam monitors and protects:

  • Delegation Scout (@ah-flash-scout): Defined in agents/ah-flash-scout.md with model: flash, commandExecutionPolicy: off, and read-only search tools (view_file, grep_search, find_by_name, list_dir). It returns compact File:StartLine-EndLine coordinates in under 200 tokens so your main frontier model avoids reading raw grep dumps.
  • /browser Isolation: Interactive web verification runs inside Antigravity's isolated webview sandbox on Flash by default, staging uploads and visual references under browser_sandbox/ without polluting workspace files.
  • /swarm & Workspace Modes: Parallel workers choose one of three Workspace Modes:
    • inherit: Shares your current working directory; suited for read-only scouts, reviewers, and verifiers.
    • share: Allocates an independent Git working tree sharing your underlying repository object store so parallel authors can edit and build concurrently without duplicating disk storage.
    • branch: Clones a fully isolated workspace branch when strict filesystem separation is required.

Claude Code Dual-Tier Architecture

Claude Code supports two execution tiers. Highbeam ships both in a single package and coordinates them automatically so guardrails never run twice on the same event.

Responsive Single-Line ah-statusline Tiers

In Claude Code, bin/ah-statusline.mjs ingests Claude Code's statusLine stdin JSON after every turn, writes an atomic snapshot to .claude/cache/ah_live_state_<sessionId>.json, and renders a single-line ANSI bar tailored to your terminal width (overridable via --columns <N> or AH_COLUMNS):

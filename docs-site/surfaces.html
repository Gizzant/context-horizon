Google Antigravity Surface Architecture

Inside Google Antigravity (App, IDE, and agy CLI), Highbeam runs as a sidecar plugin under attention-horizon-antigravity (and workspace mirror agy-horizon-flightcheck).

Sidecar Daemon & Simple / Advanced WebView

sidecars/horizon-daemon/sidecar.json starts node --no-warnings server.mjs on local port 62935 (trying 62935..62945 if busy). It mounts straight into Antigravity's side pane via SIDECAR_UI_ENTRYPOINT_AUX_PANE. You can also open it from chat via the sidecar://agy-horizon-flightcheck/horizon-daemon/ pill or run npx ctxtop --serve in a browser.

The panel offers a clean Simple View (#argonSimpleSurface) and a full Advanced Workbench (#argonAdvancedSurface). Both fit narrow 360px side panes with auto light/dark themes and strict UI safeguards tested in test/top10_token_wasters_ui.test.mjs:

  • Zone A–D Simple View & Clutter Drawer: Shows the Signal vs. Clutter bar (#tsBarSignal, #tsBarClutter, #tsStatusLabel), clear DO / AVOID / MODEL / EFFORT cards (#tsDoText, #tsAvoidText, #tsModelCard, #tsEffortCard), and a What /compact clears list (#tsWhyClears, #tsWhyList, #tsWhyTotal).
  • 1-Click Compaction Copy: Keeps #btnCompactPrimary and #btnCopyParameterizedCompact right beside #compactInstruction and #compactReclaim (plus Simple View #tsBtnCleanPrimary) for 1-click /compact copy.
  • Active Source File Protection: In the Advanced Top Consumers list (#taConsumersBody), the Ignore file (.antigravityignore) button shows up only on lockfiles, logs, build outputs, and scratch files (isIgnorablePath). It never shows on Active Source code files.
  • 3-Way Mirror Parity: When local plugin folders (~/.gemini/config/plugins/agy-horizon and agy-horizon-flightcheck) exist on disk, node scripts/sync_mirrors.mjs keeps horizon_panel.html and src/core/*.mjs byte-for-byte matched via SHA-256 checks.

Subagents, /browser, /swarm & Workspace Modes

Antigravity includes built-in multi-agent tools that Highbeam tracks and guards:

  • Delegation Scout (@ah-flash-scout): Set in agents/ah-flash-scout.md with model: flash, commandExecutionPolicy: off, and read-only search tools (view_file, grep_search, find_by_name, list_dir). It returns short File:StartLine-EndLine hits in under 200 tokens so your main model skips raw grep noise.
  • /browser Isolation: Live web checks run inside Antigravity's sandboxed webview on Flash by default. Files stage in browser_sandbox/ without cluttering your repo.
  • /swarm & Workspace Modes: Parallel workers pick one of three Workspace Modes:
    • inherit: Shares your main folder; best for read-only scouts, reviewers, and checkers.
    • share: Opens a separate Git worktree sharing your repo's git objects so multiple writers can edit and build at once without extra disk copies.
    • branch: Clones a full isolated copy when total folder separation is needed.

Claude Code Dual-Tier Architecture

Highbeam ships two hook paths for Claude Code. Today only the command hooks (Tier-2) run: Claude Code 2.1.325 has no hooks.modules setting, so the in-process module (Tier-1) is not loaded. It stays in the package for a future Claude Code in-process plugin API.

Responsive Single-Line ah-statusline Tiers

In Claude Code, bin/ah-statusline.mjs reads Claude Code's statusLine JSON after each turn. It saves a snapshot to .claude/cache/ah_live_state_<sessionId>.json (with cached hostCapabilities and any PreModelSwitch binary notes from inspectClaudeBinaryCapabilities()). Then it prints a one-line ANSI bar sized to your terminal width (set via --columns <N> or AH_COLUMNS):

Foundations

Terminology & Glossary

Every page in this guide uses the exact terms below. Filter by host or type a keyword to look up any metric, file, or concept.

A to D

ACTIVE_SET Antigravity

Clean file reads, edits, and command outputs from your last 16 steps (~8 chat turns). Files already in ACTIVE_SET pass Antigravity's PreInvocation check quietly via ALLOW_ACTIVE_SET.

Algebraic Break-Even (C*) Core Physics

The cached token count where staying on a large model (like claude-opus-5-5) costs less than switching down. Below C*, switching saves money; above C*, cold 1.25x cache writes cost more. Enforced by DET-08.

Blind-Spot Sensors Antigravity

Six zero-token local disk and git checks run during Antigravity's PreInvocation hook. They cover DIRTY_SNAP, SCHEMA_TAX, UNSEEN_CALLERS, LEGACY_POISON, QUOTA_AND_STREAM_SHIELD, and LOOP_AND_GIT_GUARD.

Claude Binary Capability Scanner (ah_claude_capabilities.json) Claude Code

A fast 4 MB chunk scanner in src/diagnostics/claudeHookCapabilities.mjs (256-byte overlap). It checks your Claude Code binary for PreModelSwitch, PostModelSwitch, PreEffortChange, and permissionBehavior==="ask" support, then saves results in .claude/cache/ah_claude_capabilities.json.

Claude Mod Laws 1-5 Claude Code

Five strict rules for code in src/core-isomorphic/ and hooks/register.js. Code must use pure ESM, zero node:* imports, zero Node globals (Buffer, unguarded process), and zero npm packages so it runs safely inside Claude Code's V8 Mod isolate.

Cold Critic Packet Core Physics

A short cross-model review note built by the /relay workflow. It packs only settled rules, the latest spec diff, and 2-3 open design questions so chat threads stay short.

Context Truncation Crisis (amputationCrisis) Core Physics

A danger state hit when active tokens pass amputation_token_threshold (140,000 in Antigravity or safeLimitTokens 147,000 in .attention-horizon.json). At that point, early Turn-0 rules risk silent server drops. It always skips the 3-turn halt cooldown.

Cost Radar Core Physics

A standalone HTML/SVG chart built by ctxtop cost-radar (or /cost-radar). It plots per-turn cache hits, thinking-token loops (DET-30), and subagent or Git worktree spans.

Delegation Scout (@ah-flash-scout) Antigravity

A read-only worker defined in agents/ah-flash-scout.md on Gemini Flash with shell tools turned off. It returns File:StartLine-EndLine matches in under 200 tokens so broad searches stay out of your main KV cache.

Distractor Debt ([D]) Claude Code

Middle-of-prompt cells (shown in magenta #F538A0) holding repeat file reads, huge CLI logs, or fixed errors. They weaken model focus and bill again on every turn.

Dual-TTL Countdown Core Physics

Two live timers tracking Anthropic's 5-minute (300s) prompt-cache window and 1-hour (3,600s) billing block. Both stop cleanly at 00:00.

E to M

Empirical Bayes Session Calibration (cal_<sessionId>.json) Core Physics

A read-only Stop-hook tracker (src/utils/sessionCalibration.mjs) saved under ~/.attention-horizon/cache/sessions/. It logs finished turns, unique API calls, starting cache size, and your 10-turn median output length, blending early turns (< 5) toward safe defaults (500 output tokens, R = 2.0).

Flight Mode Core Physics

Top-level control mode in .attention-horizon.json. Choose OFF, SILENT, COACH (default), or AUTO_PILOT (Pro mode with automatic cleanup and Hysteresis Lock).

Foreign Knowledge Bleed (MEMORY_BLEED) Antigravity

Antigravity Knowledge Items whose projectPath points to a different repo than your open workspace. Highbeam flags them so your agent checks rules before copying habits from another project.

Haiku 100k Cliff Breaker (DET-12) Claude Code

A four-step guard keeping Claude Haiku chats below the 100,000-token 5x price jump. It stays quiet under 90k, nudges at 90k-98k, warns at 98k-100k, and blocks at >= 100k.

Highbeam Airlock (ctxvault) Security & Control

A separate Sister SKU in packages/airlock/ that runs 100% locally. It scrubs secrets and PII before prompts leave your machine, independent of ctxtop.

Horizon-Aware Break-Even (C_max) & Warm-Request Payback Core Physics

Multi-turn upgrade (rule_v2) of single-turn C* in cacheGravityRouter.mjs. It finds exact paybackWarmRequests, paybackTurns, and the max cached-token hold limit C_max over your remaining turns H_post (setting C_max = Infinity when warm-read savings win out).

40-Cell Horizon Bar Core Physics

A 40-slot time bar showing your active context across Primacy, Middle Trough, and Recency zones. It displays real token counts instead of vague 0-100 scores.

Hysteresis Lock Core Physics

A router latch in AUTO_PILOT mode that stops back-and-forth model or effort flips from turn to turn. Unlock it anytime via POST /api/router/unlock-hysteresis.

Lean Hooks vs. Full Hooks Claude Code

Two setup modes in ctxtop install. Default --lean-hooks wires core tool and compact hooks for fast turns, while --full-hooks adds every extra lifecycle hook.

Micro-IPC Bridge Security & Control

A fast local JSON-RPC link in src/engine-node/ipc/ with zero npm dependencies. It uses Unix sockets on macOS/Linux and Named Pipes on Windows (15ms connect limit, 500ms call limit, 10MB max frame).

P to S

Prefix Cache Shield & TurnZeroGate Core Physics

A cache guard (DET-09, prefix_cache_shield.mjs, turn_zero_gate.mjs) that holds edits to AGENTS.md, CLAUDE.md, and rule files while your prompt cache is warm. Held edits write cleanly once the cache timer hits 0s or right after /compact.

Primacy Band & Recency Tail Core Physics

The two sharpest recall zones on the U-curve. Primacy covers Turn-0 rules at the start of the prompt (Cells 1-6), and Recency covers your newest steps at the end (Cells 33-40).

Reflector Queue & Atomic Instincts Core Physics

A local lesson queue (.agents/cache/learnings-queue.json or .claude/cache/learnings-queue.json) used by /evolve. Once 5 or more proven lessons build up (confidence >= 0.55, harmful_count == 0), it drafts a lazy-loaded skill.

Ring-0 Security Guard Security & Control

Core safety guards that run before tools start: DET-01 (unsafe shell/git), DET-02 (secret/token reads), DET-18 (untrusted repo hooks), and DET-19 (subagent prompt injection). All four block with exit 2 when they match; an internal hook fault fails open by default.

Runtime Control FSM (.ctl) Security & Control

A 5-state session switch (RUNNING, PAUSED, STEP, ABORTED, REWIND) stored at ~/.ctxtop/runtime/<sessionId>.ctl. Control it from the CLI with ctxtop control.

Scope Lock Lease (DET-20) Security & Control

A file lock saved in .agents/locks/active_scopes.json (default 900s lease, auto-clearing dead PIDs). It stops two agents or editors from writing to the same file at once.

Sidecar Daemon (horizon-daemon) Antigravity

A local-only Node HTTP and SSE server (sidecars/horizon-daemon/server.mjs on 127.0.0.1:62935..62945). It drives the Antigravity side-panel HUD.

Signal Purity & Sludge Tax Core Physics

Signal Purity is the share of useful rule and ACTIVE_SET tokens in your window. Sludge Tax is the dollar cost you pay each turn to re-send stale repeat reads and old errors.

State Baton Core Physics

A compact handoff note saved before /compact or a new chat (task.md and docs/HANDOFF_<timestamp>.md in Antigravity; .claude/cache/HANDOFF_LATEST.md in Claude Code). It keeps key choices, blockers, touched files, and one clear next step while dropping dead-end logs.

StatusLine Bridge (ah-statusline) Claude Code

A CLI helper (bin/ah-statusline.mjs) called by Claude Code's statusLine setting. It saves live session stats and prints a clean one-line ANSI bar sized to 80, 110, or 144 columns.

T to W

Tier-1 In-Process Module vs. Tier-2 Command Hook Claude Code

Tier-1 is an in-process module (hooks/register.js) that current Claude Code does not load, so it is dormant. Tier-2 runs Node scripts in hooks/handlers/*.mjs as command hooks and is what executes in every session today.

Tool-Output Surgeon Core Physics

An offline log trimmer (ctxtop doctor --prune-tools and POST /api/surgeon). It writes a .bak backup first, then trims old uncached tool outputs from local JSONL chat logs.

USTF v1 (Unified Session Trajectory Format) Core Physics

A shared JSON/JSONL log format (src/core-isomorphic/ustf/). It lines up events, call spans, token counts, and costs across Antigravity and Claude Code for ctxtop inspect.

Workspace Mode (inherit, branch, share) Antigravity

Folder modes for subagents and swarm workers. inherit shares the main folder for read-only scouts, share opens a Git worktree for parallel writers, and branch makes a full copy.

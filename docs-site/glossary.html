Foundations

Terminology & Glossary

Every page in this guide uses the exact canonical terms defined below. Filter by host primitive or type any keyword to look up an unfamiliar metric, file, or runtime concept.

A to D

ACTIVE_SET Antigravity

Clean file reads, edits, and command outputs located within the most recent 16 trajectory steps (~8 conversational turns). Targets already inside ACTIVE_SET pass Antigravity's PreInvocation scope check silently via ALLOW_ACTIVE_SET.

Algebraic Break-Even (C*) Core Physics

The exact number of warm cached prefix tokens above which staying on a higher-tier model (such as claude-opus-5-5) is cheaper than switching to a lower-tier model and paying cold 1.25x cache-write rates across the prefix. Enforced by DET-08.

Blind-Spot Sensors Antigravity

Six zero-token local filesystem and git sensors evaluated during Antigravity's PreInvocation hook: DIRTY_SNAP, SCHEMA_TAX, UNSEEN_CALLERS, LEGACY_POISON, QUOTA_AND_STREAM_SHIELD, and LOOP_AND_GIT_GUARD.

Claude Mod Laws 1-5 Claude Code

Architectural constraints governing all code inside src/core-isomorphic/ and hooks/register.js: pure ESM modules, zero node:* built-in imports, zero Node globals (Buffer, unguarded process), zero external npm packages, and deterministic synchronous or bounded execution inside Claude Code's V8 Mod isolate.

Cold Critic Packet Core Physics

A bounded cross-model review artifact generated by the /relay workflow containing only settled invariants, the current spec diff, and 2-3 open architecture questions, avoiding multi-round rebuttal thread bloat.

Context Truncation Crisis (amputationCrisis) Core Physics

High-risk state triggered when active tokens cross amputation_token_threshold (default 140,000 in Antigravity or safeLimitTokens 147,000 in .attention-horizon.json), putting Turn-0 rules at risk of silent server-side prefix eviction. Exempt from the 3-turn router halt cooldown.

Cost Radar Core Physics

A standalone, script-free HTML/SVG timeline generated by ctxtop cost-radar (or /cost-radar) plotting per-turn prefix-cache retention, thinking-token drift (DET-30 loops), and active subagent or Git worktree spans.

Delegation Scout (@ah-flash-scout) Antigravity

Read-only subagent defined in agents/ah-flash-scout.md pinned to Gemini Flash with shell execution disabled. Returns File:StartLine-EndLine coordinates in under 200 tokens to keep exploratory search dumps out of the main frontier KV cache.

Distractor Debt ([D]) Claude Code

Middle-window context cells (rendered in magenta #F538A0) representing unmodified duplicate file reads, unpruned CLI output bombs, or resolved error traces that dilute attention recall while billing on every subsequent turn.

Dual-TTL Countdown Core Physics

Simultaneous sub-second timers tracking Anthropic's 5-minute (300s) ephemeral prompt-cache window and 1-hour (3,600s) rolling billing block, clamped cleanly at 00:00.

F to M

Flight Mode Core Physics

Top-level operating posture configured in .attention-horizon.json: OFF, SILENT, COACH (default), or AUTO_PILOT (Pro tier automated actuation and Hysteresis Lock).

Foreign Knowledge Bleed (MEMORY_BLEED) Antigravity

Injected Antigravity Knowledge Items whose canonical projectPath belongs to a different repository than the active workspace, flagged so cross-project conventions are verified before adoption.

Haiku 100k Cliff Breaker (DET-12) Claude Code

Four-stage circuit breaker protecting Claude Haiku sessions from the 100,000-token 5x pricing step: nominal below 90k, advisory at 90k-98k, warning at 98k-100k, and hard halt at >= 100k.

40-Cell Horizon Bar Core Physics

Chronological 40-segment bar mapping the active context ceiling across Primacy, Middle Trough, and Recency zones in raw physical token units rather than synthetic 0-100 scores.

Hysteresis Lock Core Physics

Router damping latch in AUTO_PILOT mode that prevents rapid back-and-forth model or effort oscillation across adjacent turns; manually unlockable via POST /api/router/unlock-hysteresis.

Lean Hooks vs. Full Hooks Claude Code

Installation profiles in ctxtop install: --lean-hooks (default) wires essential pre/post tool and compaction lifecycles for minimal latency, whereas --full-hooks registers every auxiliary lifecycle handler.

Micro-IPC Bridge Security & Control

Zero-dependency JSON-RPC transport in src/engine-node/ipc/ using user-scoped Unix domain sockets on POSIX and Named Pipes on Windows (15ms connect timeout, 500ms default request timeout, 10MB max frame buffer).

P to S

Prefix Cache Shield & TurnZeroGate Core Physics

Write-fencing mechanism (DET-09, prefix_cache_shield.mjs, turn_zero_gate.mjs) that queues mutations to AGENTS.md, CLAUDE.md, and static rule files while the prompt cache is warm, flushing them only when cache TTL reaches 0s or immediately after compaction.

Primacy Band & Recency Tail Core Physics

The two high-recall regions of the U-Shaped Recall Curve: Turn-0 system anchors at the front of the prompt (Primacy, Cells 1-6) and active working steps at the end of the prompt (Recency, Cells 33-40).

Reflector Queue & Atomic Instincts Core Physics

Staged learning store (.agents/cache/learnings-queue.json or .claude/cache/learnings-queue.json) used by /evolve to accumulate repeated domain corrections until at least 5 validated instincts (confidence >= 0.55, harmful_count == 0) justify synthesizing a lazy-loaded domain skill.

Ring-0 Security Guard Security & Control

Critical pre-execution guards (including DET-01 destructive shell/git, DET-02 secret/credential access, DET-18 untrusted workspace hook injection, and DET-19 subagent prompt-injection sanitization) that fail closed on malformed hook input.

Runtime Control FSM (.ctl) Security & Control

Deterministic 5-state execution controller (RUNNING, PAUSED, STEP, ABORTED, REWIND) persisted at ~/.ctxtop/runtime/<sessionId>.ctl and operated via ctxtop control.

Scope Lock Lease (DET-20) Security & Control

Atomic multi-agent file reservation stored in .agents/locks/active_scopes.json (default 900s MCP lease TTL, auto-evicting dead PIDs) that prevents parallel subagents or editors from overwriting each other's in-flight files.

Sidecar Daemon (horizon-daemon) Antigravity

Loopback-only Node HTTP and Server-Sent Events server (sidecars/horizon-daemon/server.mjs, bound strictly to 127.0.0.1:62935..62945) powering the Antigravity auxiliary WebView pane.

Signal Purity & Sludge Tax Core Physics

Signal Purity measures the ratio of productive anchor and ACTIVE_SET tokens to total context tokens; Sludge Tax quantifies the recurring per-turn dollar cost paid to re-process stale duplicates and dead errors.

State Baton Core Physics

Compressed session checkpoint written before /compact or cross-session handoff (task.md and docs/HANDOFF_<timestamp>.md in Antigravity; .claude/cache/HANDOFF_LATEST.md in Claude Code) preserving decisions, blockers, modified artifacts, and the single next concrete action while dropping dead-end exploration traces.

StatusLine Bridge (ah-statusline) Claude Code

CLI binary (bin/ah-statusline.mjs) invoked by Claude Code's statusLine setting to persist live telemetry snapshots and output a width-adaptive (80, 110, or 144-column) single-line ANSI HUD.

T to W

Tier-1 V8 Mod vs. Tier-2 CLI Hook Claude Code

Tier-1 runs inside Claude Code's in-process V8 Mod runtime via hooks/register.js at ~0.18ms p95 and sets AH_TIER1_MOD_ACTIVE=1; Tier-2 runs spawned Node scripts in hooks/handlers/*.mjs when Mod runtime APIs are inactive.

Tool-Output Surgeon Core Physics

Offline transcript surgical pruner (ctxtop doctor --prune-tools and POST /api/surgeon) that creates an atomic .bak backup before trimming stale uncached tool payloads from local JSONL session logs.

USTF v1 (Unified Session Trajectory Format) Core Physics

Versioned JSON/JSONL schema (src/core-isomorphic/ustf/) normalizing events, call-tree spans, token buckets, and cost metrics across both Antigravity and Claude Code for ctxtop inspect.

Workspace Mode (inherit, branch, share) Antigravity

Isolation modes for delegated subagents and swarm workers: inherit reuses the parent working tree (read-only scouts), share creates a Git worktree sharing repository objects (concurrent authors), and branch clones an isolated directory copy.

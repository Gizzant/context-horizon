Detailed Command Specifications

1. /horizon

Shows your live context window health without changing any repo files.

  • In Claude Code: Opens the side attention-horizon pane when the Tier-1 V8 Mod is on (pass advanced for the full workbench). Otherwise it runs npx ah-claude receipt or npx ah-claude panel --json.
  • In Google Antigravity: Runs node --no-warnings ./src/cli/horizon_hud.mjs --emit-widget to write <artifactDirectoryPath>/horizon_widget.html. It shows the card inline via <agent-embed> and adds a 1-click sidecar://agy-horizon-flightcheck/horizon-daemon/ panel link.

2. /precheck & The 8-State Decision Rubric

Checks draft prompts and live cache state before you spend high-effort quota. In Antigravity, /precheck reads ~/.gemini/flightcheck/sessions/<conversationId>.sidecar.json in under 2ms and picks one of eight clear router states:

  1. ALLOW_SILENT: Prompt is clear and healthy, or starts with a ! / !force one-turn bypass.
  2. ALLOW_ACTIVE_SET: No file paths were typed, but the files you mean are already in your recent green ACTIVE_SET.
  3. ALLOW_PLAN_OR_SUBAGENT: Session is in /plan mode or handing off work to invoke_subagent.
  4. INJECT_CONTEXT_GUARD: Quietly adds safety notes when target files changed on disk (DIRTY_SNAP), have unseen callers (UNSEEN_CALLERS), or match old paths (LEGACY_POISON).
  5. STEER_SUBAGENT: Main cache is warm (>25,000 cached tokens and >70% Signal Purity) on low or medium effort. Nudges broad searches to invoke_subagent (@ah-flash-scout) so your main cache stays clean.
  6. HALT_HYGIENE_OR_SAFETY: Stops the turn (or warns in advisory mode) on Context Truncation Crisis (>140,000 tokens), Signal Purity under 45% on high effort, 3-strike error loops, or foreign memory bleed.
  7. HALT_EFFORT_OR_QUOTA: Flags frontier model overkill on tiny 1-line edits, 5-hour quota under 10% (quota_floor_fraction: 0.10), or single writes over 600 lines.
  8. HALT_REWRITE_SCORECARD: Prints the 4-Line Scorecard with a ready-to-paste prompt rewrite.

3. /handoff & State Compressor Taxonomy

Builds and checks a clean State Baton before /compact or starting a fresh chat. It uses a strict KEEP / DROP filter and a 5-point check:

  • KEEP: Design Decisions (with a 1-sentence why), open Blockers (Low | Medium | High), touched file Artifacts, proven State Changes, and one clear Next Action naming an exact @file or symbol.
  • DROP: Step-by-step dead ends, fixed debug notes, raw stack traces, and vague lines like "Continue working" or "WIP".

4. /cost-radar

Builds a standalone HTML/SVG timeline and sums up chat spend in three short lines from JSON fields retention, drift, and swarm. If loopTriggered is true, it leads right away with a thinking-loop alert (DET-30, or DET-21 in older Claude commands). It then suggests naming a target file plus a test, or lowering effort. Missing numbers always show -- and are never guessed.

5. /inspect

Runs ctxtop inspect --last to view call spans, tool speeds, and worker layout. It checks three local paths in order: (1) .claude/cache/ah_live_state_<sessionId>.json, (2) ~/.ctxtop/sessions/<sessionId>.jsonl, and (3) Antigravity's local brain/<sessionId> folder.

6. /evolve (RSI-01 Prefix Diet & Skill Evolution)

Keeps Turn-0 rule files short while saving proven project lessons:

  • 8,000-Token Rule Budget: Checks AGENTS.md, CLAUDE.md, and .agents/rules/*.md. If static rules pass 8,000 tokens, it offers to move topic blocks into on-demand SKILL.md files.
  • Skill Fix Routing: Sends corrections made right after a skill run back to that skill's own SKILL.md instead of bloating global rules.
  • 5-Lesson Floor: Drafts a new skill only after saving >= 5 proven lessons with confidence >= 0.55 and harmful_count == 0. It never spawns self-grading LLM subagents.
  • 1-Click Diff + TurnZeroGate: Waits for your diff approval and holds writes until your cache timer hits 0s.

7. /relay (Asymmetric Cross-Model Spec Relay)

Stops context bloat when you review specs across two or more models (suggested when relay-breaker spots Round 2+ spec churn). Your local chat acts as the Spec Owner and edits the real Markdown file on disk. Outside models act as fresh Cold Critics. Feedback sorts into S0 (Blocker), S1 (Major Flaw), T (Testable Question checked by a <30-line local script), and Defer, capped at 2 rounds.

Delegation Scout Subagent (@ah-flash-scout)

Defined in agents/ah-flash-scout.md, @ah-flash-scout keeps warm frontier chats (gemini-4-carbon, gemini-4-argon) free of huge search dumps during repo lookup:

agents/ah-flash-scout.md Manifest Contract
name: ah-flash-scout
model: flash
mainAgent: false
subagent: true
excludeDefaultComponents: true
commandExecutionPolicy: off
tools: [view_file, grep_search, find_by_name, list_dir]

Hard Output Contract: @ah-flash-scout never runs shell commands or edits files. It replies in under 200 tokens formatted as path/to/file.mjs:L10-L42 - Symbol / invariant summary.

Detailed Command Specifications

1. /horizon

Displays your current context window health without mutating any workspace files.

  • In Claude Code: Opens the docked attention-horizon pane when the Tier-1 V8 Mod is active (pass advanced for the 5-section workbench), or executes npx ah-claude receipt / npx ah-claude panel --json.
  • In Google Antigravity: Executes node --no-warnings ./src/cli/horizon_hud.mjs --emit-widget to write <artifactDirectoryPath>/horizon_widget.html, renders it inline via <agent-embed>, and surfaces the one-click sidecar://agy-horizon-flightcheck/horizon-daemon/ side-pane link.

2. /precheck & The 8-State Decision Rubric

Evaluates draft prompts and active session physics before spending high-effort frontier quota. In Antigravity, /precheck reads ~/.gemini/flightcheck/sessions/<conversationId>.sidecar.json in under 2ms and classifies the turn into one of eight deterministic router states:

  1. ALLOW_SILENT: Prompt is well-anchored, healthy, or carries a ! / !force one-turn bypass prefix.
  2. ALLOW_ACTIVE_SET: Explicit file paths were omitted, but referenced targets already reside in the recent green ACTIVE_SET.
  3. ALLOW_PLAN_OR_SUBAGENT: Session is currently inside /plan mode or delegating to invoke_subagent.
  4. INJECT_CONTEXT_GUARD: Silently appends background system guardrails when target files changed externally on disk (DIRTY_SNAP), have unseen importers (UNSEEN_CALLERS), or match deprecated globs (LEGACY_POISON).
  5. STEER_SUBAGENT: Parent context is warm (>25,000 cached tokens and >70% Signal Purity) on low/medium effort; advises delegating broad exploration to invoke_subagent (@ah-flash-scout) so the parent KV prefix stays clean.
  6. HALT_HYGIENE_OR_SAFETY: Halts execution (or warns in advisory mode) on Context Truncation Crisis (>140,000 tokens), Signal Purity below 45% on high effort, 3-strike identical command error loops, or foreign Knowledge Item bleed.
  7. HALT_EFFORT_OR_QUOTA: Flags cold-cache frontier overkill on trivial single-line edits, 5-hour quota dropping below 10% (quota_floor_fraction: 0.10), or single-shot writes exceeding 600 lines.
  8. HALT_REWRITE_SCORECARD: Emits the 4-Line Scorecard with a concrete, copy-pasteable prompt rewrite.

3. /handoff & State Compressor Taxonomy

Audits and writes a lossless State Baton before context compaction or cross-session rotation. Enforces a strict KEEP / DROP filter and a 5-point verification checklist:

  • KEEP: Architectural Decisions (with 1-sentence rationale), active Blockers (with Low | Medium | High severity), explicit modified file Artifacts, verified milestone State Changes, and one concrete unblocked Next Action naming an exact @file or symbol.
  • DROP: Chronological trial-and-error narratives, resolved temporary debug scaffolding, raw stack traces, and vague directives such as "Continue working" or "WIP".

4. /cost-radar

Generates a self-contained HTML/SVG timeline summarizing session spend in at most three lines using JSON fields retention, drift, and swarm. When loopTriggered is true, the summary leads immediately with a scratchpad-loop alert (DET-30, aliased as DET-21 in legacy Claude commands) and recommends anchoring a concrete target file + acceptance test or stepping reasoning effort down. Unmeasured metrics always display -- and are never fabricated.

5. /inspect

Runs ctxtop inspect --last to inspect execution spans, tool latencies, and swarm topology. Resolution checks three local stores in order: (1) .claude/cache/ah_live_state_<sessionId>.json, (2) ~/.ctxtop/sessions/<sessionId>.jsonl, and (3) Antigravity's local brain/<sessionId> directory.

6. /evolve (RSI-01 Prefix Diet & Skill Evolution)

Keeps Turn-0 static rule files lean while preserving validated domain lessons:

  • 8,000-Token Static Prefix Budget: Audits AGENTS.md / CLAUDE.md and .agents/rules/*.md. When static rules exceed 8,000 tokens, proposes extracting domain sections into lazy-loaded SKILL.md bundles.
  • Skill Fault Delta Routing: Routes post-skill user corrections directly to the offending skill's SKILL.md rather than inflating global rules.
  • 5-Instinct Synthesis Floor: Drafts a new domain skill only after accumulating >= 5 validated instincts with confidence >= 0.55 and harmful_count == 0, strictly forbidding recursive LLM self-critique subagents.
  • 1-Click Diff + TurnZeroGate: Requires explicit user diff approval and queues writes until prompt-cache TTL reaches 0s.

7. /relay (Asymmetric Cross-Model Spec Relay)

Prevents quadratic context bloat when iterating on specifications across multiple frontier models (automatically recommended when relay-breaker detects Round 2+ spec churn). Assigns the local session as the Stateful Spec Owner (editing the canonical Markdown spec on disk) and external models as stateless Cold Critics, triaging feedback into S0 (Blocker), S1 (Major Flaw), T (Testable Runtime Question settled via a <30-line local script), and Defer, with a strict 2-round convergence cap.

Delegation Scout Subagent (@ah-flash-scout)

Defined in agents/ah-flash-scout.md, @ah-flash-scout protects warm frontier sessions (gemini-4-carbon, gemini-4-argon) from ingesting multi-thousand-token search dumps during codebase discovery:

agents/ah-flash-scout.md Manifest Contract
name: ah-flash-scout
model: flash
mainAgent: false
subagent: true
excludeDefaultComponents: true
commandExecutionPolicy: off
tools: [view_file, grep_search, find_by_name, list_dir]

Hard Output Contract: @ah-flash-scout never executes shell commands or edits files, and returns strictly under 200 tokens formatted as path/to/file.mjs:L10-L42 - Symbol / invariant summary.

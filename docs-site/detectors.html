Guardrails & Detector Catalog

Highbeam runs 32 core detectors (DET-01..DET-32), 8 habit coaches, and 6 local Blind-Spot Sensors in fast local JavaScript. Zero extra LLM judge tokens are ever spent.

Canonical Detector Catalog (DET-01 to DET-32)

Four rules carry a Ring-0 Security tag (DET-01, DET-02, DET-18, DET-19). Ring-0 guards protect secrets, shell safety, repo settings, and subagent inputs, and block unsafe calls with exit 2. If the hook itself hits an internal fault it fails open by default (see Hooks Lifecycle).

Semantic Habit Detectors (semanticDetectors)

Along with numbered IDs, .attention-horizon.json includes eight readable habit slugs you can set via highbeam config set <slug> <default|off|warn|block>:

  • formatter-bypass: Suggests running prettier or eslint once at the end instead of burning turns after every small edit.
  • drip-feed: Spots rapid 1-line follow-up prompts that pay extra cache-write fees when steps could be grouped.
  • vague-prompt-rubric (aliases: prompt-decomposer, scope-brake): Scores broad prompts that miss target files or test goals.
  • effort-overkill: Flags max or high effort frontier use on simple typos, renames, or formatting.
  • post-commit-handoff: Nudges you to compact or start fresh after finishing a key git commit.
  • vision-screenshot-coach: Suggests reading DOM or CSS text instead of sending repeat full screenshots (and warns on DET-20 overage HTTP 400 bugs).
  • micro-skills: Suggests turning repeat workflow fixes (after microSkillConfirmSessions: 2) into reusable skills.
  • relay-breaker (alias: spec-relay): Flags Round 2+ multi-model spec debates and suggests switching to /relay.

Antigravity 6 Local Blind-Spot Sensors

During Antigravity's PreInvocation hook, src/core/blindspot_sensors.mjs runs six fast local disk checks:

  1. DIRTY_SNAP: Spots when a file read earlier in chat was changed on disk by you, a formatter, or git.
  2. SCHEMA_TAX: Measures Turn-0 MCP and tool schema token size against your window limit.
  3. UNSEEN_CALLERS: Scans repo imports when an exported function changes so callers outside ACTIVE_SET do not break.
  4. LEGACY_POISON: Warns when reads pull code from deprecated_paths (**/legacy/**, **/deprecated/**, **/v1/**).
  5. QUOTA_AND_STREAM_SHIELD: Guards against low 5-hour quota (<10%) and single-file writes over 600 lines.
  6. LOOP_AND_GIT_GUARD: Pairs 3-strike command loop checks with dirty-tree reminders.

Guardrails & Detector Catalog

Highbeam evaluates 32 canonical detectors (DET-01..DET-32), 8 semantic habit coaches, and 6 local Blind-Spot Sensors using pure deterministic JavaScript. Zero extra LLM judge tokens are ever consumed.

Canonical Detector Catalog (DET-01 to DET-32)

Four detectors carry a Ring-0 Security designation (DET-01, DET-02, DET-18, DET-19). Ring-0 guards protect credentials, shell integrity, workspace settings, and subagent prompt boundaries, and fail closed on malformed hook payloads.

Semantic Habit Detectors (semanticDetectors)

In addition to numbered IDs, .attention-horizon.json supports eight human-readable habit coaching slugs configurable via ctxtop config set <slug> <default|off|warn|block>:

  • formatter-bypass: Advises batching prettier/eslint runs at task end rather than burning turns after every single-file edit.
  • drip-feed: Detects fragmented 1-sentence follow-up prompts that repeatedly pay cache-write overhead when instructions could be grouped.
  • vague-prompt-rubric (aliases: prompt-decomposer, scope-brake): Scores unanchored prompts lacking target files or verification criteria.
  • effort-overkill: Flags max/high effort frontier usage on trivial typo, rename, or formatting tasks.
  • post-commit-handoff: Prompts rotating or compacting context cleanly after a milestone git commit completes.
  • vision-screenshot-coach: Advises inspecting DOM/CSS text or bounded snippets when repeated full-resolution screenshots inflate token spend (and guards against DET-20 overage HTTP 400 bugs).
  • micro-skills: Suggests codifying repeated multi-session workflow corrections (after microSkillConfirmSessions: 2) into reusable micro-skills.
  • relay-breaker (alias: spec-relay): Flags Round 2+ multi-model prose rebuttal loops and recommends switching to the /relay protocol.

Antigravity 6 Local Blind-Spot Sensors

During Antigravity's PreInvocation hook, src/core/blindspot_sensors.mjs runs six sub-millisecond filesystem checks:

  1. DIRTY_SNAP: Detects when a file previously read into context was modified externally by the user, formatter, or git checkout.
  2. SCHEMA_TAX: Measures Turn-0 MCP and tool-declaration token weight against session headroom.
  3. UNSEEN_CALLERS: Scans workspace imports when a public export signature is being refactored so callers outside ACTIVE_SET are not broken.
  4. LEGACY_POISON: Warns when reads pull patterns from deprecated_paths (**/legacy/**, **/deprecated/**, **/v1/**).
  5. QUOTA_AND_STREAM_SHIELD: Guards against 5-hour quota exhaustion (<10%) and single-file writes exceeding 600 lines.
  6. LOOP_AND_GIT_GUARD: Combines 3-strike command loop detection with uncheckpointed dirty-tree drift warnings.

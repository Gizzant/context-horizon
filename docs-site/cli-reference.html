CLI & Binaries Reference

Highbeam registers 12 CLI binary entrypoints and 3 execution shims across four runtime targets. Every subcommand below is documented directly from bin/ctxtop.mjs, bin/ah-statusline.mjs, and src/cli/*.mjs.

Package Binaries & Entrypoints

Binary Name(s) Target Script Primary Purpose
ctxtop, ah, attention-horizon, ah-claude, attention-horizon-claude ./bin/ctxtop.mjs Unified cross-platform CLI dispatcher for installation, receipts, Cost Radar, configuration, runtime control, inspection, and Pro licensing.
ah-statusline ./bin/ah-statusline.mjs Standalone Claude Code statusLine stdin JSON bridge rendering 80, 110, or 144-column ANSI telemetry bars.
attention-horizon-antigravity, ah-antigravity, agy-horizon, agy-horizon-flightcheck ./src/cli/init.mjs Antigravity-focused CLI launcher for loopback WebView serving (--serve), terminal crisis demos (--demo-animate), FTS5 command execution (exec), and FTS5 log queries (log-search).
ah-mcp, ctxtop-mcp ./packages/mcp/src/server.mjs Zero-dependency Model Context Protocol JSON-RPC 2.0 stdio server for Cursor, Windsurf, Claude Code, and Antigravity.

Complete Subcommand Reference

ctxtop init

Non-destructively installs Highbeam across one or more host environments.

Synopsis
ctxtop init [--antigravity] [--claude] [--mcp | --cursor | --windsurf] [--all]
            [--global | -g | --workspace | --project]
            [--lean-hooks | --full-hooks] [--dry-run] [--dedupe] [--json]
  • --antigravity: Installs Google Antigravity plugin manifests, rules, skills, and sidecar hooks.
  • --claude: Merges Claude Code lifecycle hooks and ah-statusline into settings.json.
  • --mcp / --cursor / --windsurf: Writes the attention-horizon stdio server entry into .cursor/mcp.json (or ~/.cursor/mcp.json with --global).
  • --all / -a: Configures every detected host surface in one pass.
  • --lean-hooks (default) vs. --full-hooks: Selects minimal-latency essential hooks versus full lifecycle coverage.
  • --dry-run: Prints planned target paths and merge actions without touching disk.
  • --dedupe: Removes duplicate Highbeam hook entries from prior installations while keeping unrelated user hooks intact.

ctxtop install & ctxtop uninstall

Targeted installer and uninstaller for Claude Code settings.json files, creating a timestamped backup on merge.

Synopsis
ctxtop install [--global | -g | --project] [--lean-hooks | --full-hooks] [--json]
ctxtop uninstall [--global | -g | --project] [--json]

Defaults to --project (<cwd>/.claude/settings.json) when --global is omitted.

ctxtop doctor & ctxtop prune

Validates host contracts, model catalogs, hook error logs, and performs optional offline maintenance and surgical pruning.

Synopsis
ctxtop doctor [--diagnostic | --bug-report] [--json]
              [--prune-tools | --prune | --uncached-tail | --tail]
              [--transcript <path>] [--reap-orphans] [--handoff | --distill]
              [--storage-gc | --gc-cursor | --recover-brain] [--vscdb <path>] [--dry-run]
  • --diagnostic / --bug-report: Emits a zero-PII Markdown (or --json) diagnostic bundle with home paths redacted.
  • --prune-tools / --uncached-tail (also agy-horizon prune): Invokes the Tool-Output Surgeon on the active JSONL transcript (or --transcript <path>), creating a .bak backup before trimming stale uncached tool payloads.
  • --reap-orphans: Scans and terminates leaked zombie language-server or test child processes.
  • --handoff / --distill: Generates a timestamped Baton Pass handoff Markdown file in docs/.
  • --recover-brain: Relinks orphaned Antigravity session brain directories after profile migrations.
  • --gc-cursor --vscdb <path>: Streams and compacts bloated Cursor state.vscdb SQLite files by removing orphan rows.
  • --dry-run: Simulates pruning or storage garbage collection without modifying files.

ctxtop verify (alias: verify-checksums)

Computes pure-JS SHA-256 hashes (CRLF-normalized) for every release file listed in CHECKSUMS.sha256 and exits 0 when zero mismatches exist.

Synopsis
ctxtop verify [--json]

ctxtop receipt

Renders the verified Tokens & USD Saved receipt in terminal text, Git-commit Markdown, standalone HTML, JSON, or Pro SHA-256 PDF 1.4 format.

Synopsis
ctxtop receipt [--simple | --4-rank | --advanced]
               [--markdown | --md | --git | --html | --pdf | --json]
               [--out <path>]

Note: Passing --pdf on the Free tier exits with code 2 and displays your 30-day shadow USD savings alongside local trial instructions (ctxtop pro trial).

ctxtop panel

Writes a self-contained, zero-socket Claude Code HTML HUD snapshot (default output: ~/.claude/attention-horizon/horizon_panel.html).

Synopsis
ctxtop panel [--advanced] [--out <file.html>] [--json]

ctxtop cost-radar (alias: radar)

Writes a script-free HTML/SVG timeline showing per-turn prefix-cache retention, thinking-token drift, and Git worktree swarm topology (default output: ~/.claude/attention-horizon/cost_radar.html).

Synopsis
ctxtop cost-radar [--out <file.html>] [--demo] [--share] [--json]

ctxtop statusline & ah-statusline

Reads Claude Code's statusLine JSON payload from stdin (1,500ms bounded timeout), updates .claude/cache/ah_live_state_<sessionId>.json, and prints a responsive single-line ANSI bar.

Synopsis
ah-statusline [--demo] [--columns <N> | --cols <N>]

ctxtop postmortem & ctxtop roast

Scans recent local sessions to classify failure archetypes (CONTEXT_ROT_DECAY, VERIFICATION_CHURN, SPEC_AMBIGUITY, CLEAN), identify top duplicate-read files, audit Turn-0 MCP overhead, and emit shareable ASCII or Markdown forensic summaries.

Synopsis
ctxtop postmortem [--last <N>] [--roast] [--demo] [--json]
ctxtop roast [--demo] [--markdown | --md] [--json]

--last defaults to 15 sessions. Writes session_analysis_report.md and conversation_diagnostics.jsonl when writeFiles is enabled.

ctxtop inspect

Normalizes any Claude Code live snapshot, USTF v1 log, or Antigravity brain directory into a USTF v1 trajectory with event counts, span trees, cached vs. uncached tokens, and USD cost.

Synopsis
ctxtop inspect [<session-id> | --session <id> | --last] [--out <file.json>] [--json]

Antigravity Server, Demos & FTS5 Execution Wrappers

Invoked via agy-horizon (src/cli/init.mjs) or src/cli/horizon_hud.mjs:

Synopsis
# Start loopback HTTP/SSE daemon on 127.0.0.1:62935..62945
agy-horizon ui [--open | --no-open] [--demo]
ctxtop --serve

# Run 5-stage synthetic terminal crisis showcase or emit Studio HTML widget
agy-horizon demo [--demo-animate] [--scenario <1..5>] [--harness <antigravity|claude-code>]
node src/cli/horizon_hud.mjs --emit-widget

# Execute a verbose shell command through the lossless FTS5 compressor (>4,096 chars archived)
agy-horizon exec <command...>

# Query archived FTS5 CLI logs by keyword across turns
agy-horizon log-search "<fts5-query>"

ctxtop config

Lists, sets, or resets per-detector overrides in .attention-horizon.json (project default) or ~/.attention-horizon/config.json (--global).

Synopsis
ctxtop config [list] [--global | -g] [--json]
ctxtop config set <DET-01..DET-20 | habit-slug> <default | off | warn | block> [--global | -g]
ctxtop config reset [--global | -g]

ctxtop control

Transitions the 5-state Runtime Control FSM at ~/.ctxtop/runtime/<sessionId>.ctl and notifies any warm Micro-IPC daemon via control.transition.

Synopsis
ctxtop control <status | pause | resume | step | abort | rewind>
               [--session <id>] [--target <turn> | --turn <turn>]

Note: abort transitions the session into terminal ABORTED state, which cannot be resumed without starting a new session or clearing the .ctl file.

ctxtop license (pro), tiers & team-pack

Manages offline Ed25519 Pro licenses, 14-day local trials, and BYO-Grafana / Datadog OpenTelemetry bundles.

Synopsis
ctxtop tiers [--json]
ctxtop pro [status | tiers | trial | activate <ed25519-token> | deactivate] [--json]
ctxtop team-pack [--out <dir>] [--org "<Org Name>"] [--preview] [--json]

Execution Shims & Standard Exit Codes

Three standalone shims inside src/shims/ support direct shell integration:

  • src/shims/agy_cli_compressor.mjs: Standalone ANSI/carriage-return scrubber and SQLite FTS5 output archiver honoring AGY_CONVERSATION_ID.
  • src/shims/agy_git_guard.mjs: Standalone option-argument-aware git and shell command validator backing DET-01.
  • src/shims/ah_log_query.mjs: Lightweight FTS5 full-text reader for retrieving offloaded lines from .ctxtop/cache/artifacts_fts5.db.
Exit Code Meaning Across CLI & Hook Binaries
0 Command succeeded, checksum/doctor checks passed, or structured hook JSON decision (allow / deny / ask) emitted to stdout.
1 Invalid CLI subcommand/argument, missing target session, checksum mismatch, or failed doctor health check.
2 Hard veto block in Claude Code Tier-2 CLI hooks (diagnostic written to stderr with empty stdout) OR Pro/Team commercial entitlement gate on ctxtop receipt --pdf and ctxtop team-pack (when --preview is omitted).

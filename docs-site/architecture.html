System Architecture & Internals

Highbeam is organized as a zero-dependency six-package monorepo separating pure isomorphic context physics from Node.js storage engines and host-specific adapters.

1. Six-Package Workspace Topology

Root package.json declares six workspaces under packages/* backed by shared source trees in src/core-isomorphic/, src/engine-node/, and src/core/:

2. Claude Mod Laws 1-5 & Pure-JS Cryptography

Because Claude Code's Tier-1 Mod isolate executes inside a sandboxed V8 context without Node.js built-ins, every module inside src/core-isomorphic/ obeys five statically tested laws (verified in test/mod_static_compliance.test.mjs):

  1. Zero node:* Imports: No node:fs, node:path, node:crypto, or node:child_process imports anywhere in the isomorphic graph.
  2. Zero Unguarded Node Globals: Never references bare Buffer or process without safe globalThis feature guards.
  3. Zero External npm Dependencies: Eliminates supply-chain drift and bundler build steps.
  4. Pure Deterministic Hashing: Uses custom pure-JS 64-bit FNV-1a (fnv1a64.mjs) for content fingerprinting and pure-JS SHA-256 (sha256HexPure) for release verification and receipt signing.
  5. Sub-Millisecond Hot Path: Keeps evaluatePreToolUse and computeBreakEven at ~0.18ms p95.

3. Lossless FTS5 CLI Output Compressor

Verbose test suites and package installs routinely emit 50,000+ characters of progress bars and passing test noise. Implemented in src/core/fts5_output_compressor.mjs and src/shims/agy_cli_compressor.mjs (DET-07), the offloader processes shell output in four stages:

  1. ANSI & Carriage-Return Scrubbing: Strips terminal color sequences and collapses \r spinner overwrites before evaluating the 4,096-character compression threshold.
  2. Domain Noise Profiles: Applies specialized filters for cargo test, npm install, and verbose test runners while retaining every failing assertion, stack frame, and compiler diagnostic (Critical Error-Line Recovery).
  3. SQLite FTS5 & Content-Addressed Archival: Writes the full raw transcript to .ctxtop/cache/artifacts/ah_<sha256>.txt and indexes every line in .ctxtop/cache/artifacts_fts5.db.
  4. Searchable Digest Injection: Returns a compact head/tail + error-line summary to the model alongside an exact agy-horizon log-search "<query>" command so zero debugging detail is ever lost.

5. USTF v1 & 3-Way SHA-256 Mirror Parity

  • USTF v1 (src/core-isomorphic/ustf/): Normalizes heterogeneous Antigravity SQLite/JSONL steps and Claude Code event streams into a single schema (version: "1.0.0", sessionId, harness, modelId, usage: { uncached, cacheWrite5m, cacheWrite1h, cacheRead, output, thinking, costUSD }, events, spans).
  • Release & Mirror Parity Pipeline: Whenever core or WebView files change, contributors run node scripts/sync_mirrors.mjs, followed by node scripts/generate_checksums.mjs and node bin/ctxtop.mjs verify --json, ensuring root sources and installed plugin mirrors match byte-for-byte.

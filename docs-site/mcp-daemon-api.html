MCP Server, HTTP Daemon & Micro-IPC API

Highbeam exposes three local-only APIs: a zero-dependency MCP stdio server for external AI editors, a local HTTP/SSE server for the WebView panel, and a fast Micro-IPC socket (<15ms) for warm hook calls.

1. MCP Stdio Server (@ctxtop/mcp)

Built in packages/mcp/src/server.mjs (commands ah-mcp and ctxtop-mcp, protocol 2024-11-05). The server reads both newline-delimited JSON-RPC 2.0 lines and LSP-style Content-Length: <bytes>\r\n\r\n frames over stdin and stdout.

.cursor/mcp.json Registration
{
  "mcpServers": {
    "attention-horizon": {
      "command": "npx",
      "args": ["-y", "--package=ctxtop", "ctxtop-mcp"]
    }
  }
}

2. Loopback HTTP & SSE Daemon API

sidecars/horizon-daemon/server.mjs binds only to 127.0.0.1 on port 62935 (trying up to 62945 if busy). It rejects POST bodies over 4,096 bytes with HTTP 400 or 413.

3. Micro-IPC Socket Protocol (@ctxtop/engine-node)

Built in src/engine-node/ipc/protocol.mjs, client.mjs, and server.mjs. Micro-IPC lets short-lived CLI hooks hand checks off to a warm local daemon over a Unix socket (macOS/Linux) or Named Pipe (Windows, custom path via CTXTOP_IPC_PATH).

  • Limits: MAX_BUFFER_SIZE_BYTES = 10,485,760 (10 MB), DEFAULT_CONNECT_TIMEOUT_MS = 15, DEFAULT_REQUEST_TIMEOUT_MS = 500 (raised to 600,000ms while a session is PAUSED).
  • Fail-Safe Fallback: If no warm daemon replies within 15ms, the hook runs CircuitBreakerEngine and checks .ctl files directly in process with zero errors.
  • Standard JSON-RPC 2.0 Error Codes: -32700 (PARSE_ERROR), -32600 (INVALID_REQUEST), -32601 (METHOD_NOT_FOUND), -32602 (INVALID_PARAMS), and -32603 (INTERNAL_ERROR).

Configuration, Permissions & Security Sandbox

Highbeam layers project-local configuration over user-global defaults while enforcing non-bypassable Ring-0 boundaries, read-only SQLite locks, and loopback-only network sockets.

1. Unified Config Schema (.attention-horizon.json)

Platform Quirks & WebView Window Settings Schemas

config/platformQuirks.json: Configures two upstream platform safeguards: visionOverageHttp400 (warns via DET-20 when AI Credit Overages are active and an image attachment would trigger upstream HTTP 400 "Unable to process input image") and hybridQuotaLockout (DET-16: throttles to 1 worker at 80% quota, hard-asks at 90%, caps subagents at 40,000 tokens / 12 turns to prevent 168-hour lockouts).

<cacheDir>/settings.json (src/core/settings.mjs): Stores WebView slider overrides { safeLimitTokens, reminderAtPct, modelOverrides }, clamped strictly to 20,000..1,048,576 tokens and 50%..99% reminder thresholds, written atomically via PID-scoped rename.

4. Zero-Trust Security Sandbox & Branch Isolation

Defined in SECURITY.md and verified across automated static compliance suites (test/mod_static_compliance.test.mjs), Highbeam enforces five strict security invariants:

  1. Zero Outbound Network Calls: Neither the CLI, lifecycle hooks, V8 Mod, MCP server, nor HTTP daemon imports external HTTP clients or makes DNS/HTTPS requests.
  2. Loopback-Only Binding & Payload Caps: sidecars/horizon-daemon/server.mjs binds strictly to 127.0.0.1 and rejects POST bodies larger than 4,096 bytes to eliminate cross-origin loopback abuse.
  3. Strict Read-Only Telemetry Descriptors: All Antigravity SQLite databases open with { readOnly: true } (SQLITE_OPEN_READONLY) inside try / finally blocks, and JSONL transcripts open with 'r'.
  4. Ring-0 Self-Modification Prevention: DET-18 blocks agents from editing .claude/settings.json or hooks.json to auto-approve commands or disable guardrails mid-session.
  5. Safe Parallel Branch Isolation: Whenever multiple agents write concurrently, prefer Git worktrees (workspace: "share" or git worktree add) paired with .agents/locks/active_scopes.json leases (DET-20) so parallel workers never corrupt a shared working index.

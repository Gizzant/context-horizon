Configuration, Permissions & Security Sandbox

Highbeam layers project settings over user defaults while keeping strict Ring-0 safety checks, read-only SQLite reads, and local-only ports.

1. Unified Config Schema (.attention-horizon.json)

Built into src/core-isomorphic/config/horizonConfig.mjs, Highbeam merges settings from lowest to highest priority: built-in defaults → global ~/.attention-horizon/config.json → project <workspace>/.attention-horizon.json.

2. Antigravity Router Schema (default_flightcheck.json)

Antigravity's PreInvocation router loads defaults from config/default_flightcheck.json and applies your changes from ~/.gemini/flightcheck/config.json. See Antigravity Router Levels & Cooldowns for how hook_level works with halt_cooldown_turns:

Key Default Operational Meaning
hook_level "guard" Router mode: "guard" stops with a scorecard; "advisory" adds soft warnings only.
halt_cooldown_turns 3 Turns skipped between router stops to avoid nag loops (Context Truncation Crisis skips cooldown).
cold_session_max_turns 3 Early turns checked for missing file or scope anchors.
trust_decay_turn_threshold 10 Turn count where deeper context drift checks turn on.
warm_cache_lock_tokens 50000 Cached token count that locks rule files so edits do not break a warm cache.
subagent_min_cache_tokens / subagent_min_purity_pct 25000 / 70.0 Warm main-chat threshold that triggers STEER_SUBAGENT tips for broad repo searches.
compact_halt_purity_pct 45.0 Signal Purity floor where high-effort turns suggest trimming or running /compact.
amputation_token_threshold 140000 Token limit that raises amputationCrisis (Context Truncation Risk).
quota_floor_fraction 0.10 5-hour quota floor (10%) that triggers HALT_EFFORT_OR_QUOTA quota-saving tips.
max_single_write_lines / max_tool_payload_tokens 600 / 25000 Max lines for one file write and max raw tool output size before archiving.
uncheckpointed_dirty_file_limit 4 Dirty file count that nudges you to run a test or git check.
consecutive_error_strike_limit 3 Repeat identical tool errors allowed before the 3-strike breaker stops the loop.
plan_revision_warn / split_recommend_minutes 3 / 45 Plan rewrite count and chat length in minutes that suggest starting a fresh session.
handoff_audit_enabled / deprecated_paths true / ["**/legacy/**", "**/deprecated/**", "**/v1/**"] Turns on 5-point State Baton checks and lists path globs tagged as LEGACY_POISON.
Platform Quirks & WebView Window Settings Schemas

config/platformQuirks.json: Sets two host safety guards. First, visionOverageHttp400 warns via DET-20 when AI Credit Overages are on and an image would fail with HTTP 400 ("Unable to process input image"). Second, hybridQuotaLockout (DET-16) caps workers to 1 at 80% quota, asks at 90%, and limits subagents to 40,000 tokens or 12 turns to prevent 168-hour lockouts.

<cacheDir>/settings.json (src/core/settings.mjs): Saves WebView slider values { safeLimitTokens, reminderAtPct, modelOverrides }. Values stay clamped to 20,000..1,048,576 tokens and 50%..99%, and save safely via atomic rename.

4. Zero-Trust Security Sandbox & Branch Isolation

Backed by SECURITY.md and checked in test/mod_static_compliance.test.mjs, Highbeam enforces five strict safety rules:

  1. Zero Outbound Network Calls: The CLI, hooks, MCP server, and local HTTP server never make external HTTP or DNS requests.
  2. Localhost Binding & Size Caps: sidecars/horizon-daemon/server.mjs binds only to 127.0.0.1 and drops POST bodies over 4,096 bytes.
  3. Read-Only Session Reads: Every Antigravity SQLite database opens with { readOnly: true } (SQLITE_OPEN_READONLY) inside try / finally, and JSONL files open with 'r'.
  4. No Self-Edits to Guard Configs: DET-18 stops agents from editing .claude/settings.json or hooks.json to turn off safety checks mid-chat.
  5. Safe Parallel Worktrees: When two or more agents write code at once, pair Git worktrees (workspace: "share" or git worktree add) with .agents/locks/active_scopes.json file locks (DET-20) so edits never clash.

Highbeam runs zero-token guards and gathers turn stats through fast host hooks. This chapter lists every hook event, tool matcher, JSON format, timeout, and control state.

Claude Code Tier-1 In-Process V8 Mod (hooks/register.js)

Listed under hooks.modules in hooks/hooks.json, hooks/register.js runs straight inside Claude Code's V8 isolate with zero process startup cost (~0.18ms p95). It sets AH_TIER1_MOD_ACTIVE=1 and wires 10 handlers:

  • on('file.changed'): Spots outside disk edits so stale in-chat file copies get flagged right away.
  • on('tool.call'): Checks tool calls inside V8, running CircuitBreakerEngine.evaluatePreToolUse, 3rd-read AST stubs, and Scope Lock checks.
  • on('turn.step') & on('turn.complete'): Updates live token counts, Dual-TTL timers, thinking-loop checks, and the 30-day Saved Quota Ledger in $.store.
  • on('classic.SessionStart'): Loads the State Baton from .claude/cache/HANDOFF_LATEST.md on startup|resume|clear|compact|fork.
  • on('classic.PreCompact') & on('classic.PostCompact'): Saves active rules before /compact and writes held TurnZeroGate rule updates right after while the cache is cold.
  • on('classic.Stop'): Runs stop-time test checks (DET-14) and placeholder checks (DET-15).
  • on('command.horizon') & on('ui.render'): Draws the docked Simple View or 5-part Advanced Workbench inside Claude Code.

Chunked Binary Capability Probing (claudeHookCapabilities.mjs)

Built into src/diagnostics/claudeHookCapabilities.mjs, Highbeam checks Claude Code hook support on disk without spawning slow subshells or filling V8 memory. inspectClaudeBinaryCapabilities() streams your claude binary (found via CLAUDE_BIN or PATH, unwrapping Windows .cmd shims) in 4 MB chunks with a 256-byte overlap. It checks 10 markers: PreModelSwitch, PostModelSwitch, PreEffortChange, keys from_model, to_model, prompt_cache_warm, context_tokens, permissionBehavior==="ask", ask prompt text, and blocked_by_hook. Results save by (binaryPath, size, mtimeMs) in .claude/cache/ah_claude_capabilities.json so ctxtop install skips PostModelSwitch on older Claude builds (omittedUnsupportedHooks).

Exit Code & JSON Wire Contract (hookIo.mjs)

Claude Code Tier-2 scripts follow four strict wire rules in hooks/handlers/hookIo.mjs:

  1. Quiet Pass: Exit 0 with empty stdout.
  2. JSON Decision: Print valid JSON (like {"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"deny","permissionDecisionReason":"..."}} or updatedInput) to stdout and exit 0.
  3. Hard Block: Print one short note to stderr and exit 2 with empty stdout. Never wired on WorktreeCreate or PermissionRequest.
  4. Bad Input Handling: Guard hooks fail closed (exit 2) on broken stdin JSON. Advisory stats hooks pass { allowMalformed: true } and fail safe (exit 0).

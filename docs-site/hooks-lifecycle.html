Claude Code Tier-1 In-Process V8 Mod (hooks/register.js)

Declared under hooks.modules in hooks/hooks.json, hooks/register.js loads directly into Claude Code's V8 isolate with zero process-spawn overhead (~0.18ms p95). It sets AH_TIER1_MOD_ACTIVE=1 and registers 10 literal handlers:

  • on('file.changed'): Tracks external workspace edits on disk to invalidate stale in-context read assumptions.
  • on('tool.call'): Intercepts tool invocations synchronously inside V8, running CircuitBreakerEngine.evaluatePreToolUse, 3rd-read AST signature stub folding, and Scope Lock Lease checks.
  • on('turn.step') & on('turn.complete'): Updates live token envelopes, Dual-TTL countdowns, thinking-drift monitors, and the 30-day Saved Quota Ledger inside $.store.
  • on('classic.SessionStart'): Hydrates the State Baton from .claude/cache/HANDOFF_LATEST.md across startup|resume|clear|compact|fork transitions.
  • on('classic.PreCompact') & on('classic.PostCompact'): Snapshots active constraints before compaction and flushes queued TurnZeroGate rule updates immediately after compaction while the prefix is cold.
  • on('classic.Stop'): Runs stop-phase test verification (DET-14) and batched formatter/placeholder audits (DET-15).
  • on('command.horizon') & on('ui.render'): Renders the docked Simple View (4-Rank HUD) or 5-Section Advanced Workbench inside Claude Code.

Exit Code & JSON Wire Contract (hookIo.mjs)

Claude Code Tier-2 handlers strictly follow four wire rules in hooks/handlers/hookIo.mjs:

  1. Silent Pass-Through: Exit 0 with empty stdout.
  2. Structured JSON Decision: Write valid JSON (such as {"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"deny","permissionDecisionReason":"..."}} or updatedInput) to stdout and exit 0.
  3. Hard Veto Block: Write a concise single-block explanation to stderr and exit 2 with strictly empty stdout. Never registered on WorktreeCreate or PermissionRequest.
  4. Malformed Input Fail-Closed vs. Fail-Safe: Guard hooks reject malformed non-object stdin JSON with SyntaxError and fail closed (exit 2), whereas advisory telemetry hooks pass { allowMalformed: true } and fail safe (exit 0).
